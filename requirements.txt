# SIRAT AI runtime dependencies.

# Deliberately short. Every entry below is imported by code that runs on a
# normal path; nothing is here "in case it is useful later". Four libraries
# that were considered and rejected, with the reason, so the decision does not
# get re-litigated:
#
#   scipy          pulled in for one normal-distribution quantile. That is two
#                  hard-coded constants in risk.py (1.645 / 2.326) against a
#                  ~35 MB dependency with a compiled toolchain on Windows.
#   scikit-learn   nothing here fits a model yet. It belongs in the same commit
#                  as the first one, not before it.
#   PyPortfolioOpt depends on cvxpy, whose solvers need a C++ build chain on
#                  Windows. portfolio.py's sizing is risk-parity with explicit
#                  caps -- closed-form, no optimiser, and auditable line by
#                  line, which matters more here than mean-variance elegance.
#   yfinance       the benchmark is شاخص کل, which comes from TSETMC. Yahoo has
#                  no Tehran data, so it would fetch nothing this project uses.
#
# numpy is listed explicitly even though pandas requires it: risk.py and
# performance.py import it directly, and a dependency you import is a
# dependency you declare.
